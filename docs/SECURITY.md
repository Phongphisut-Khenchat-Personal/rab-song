# ความปลอดภัยและความเป็นส่วนตัว

## บัญชี

- รหัสผ่านเก็บด้วย scrypt ไม่เก็บรหัสผ่านดิบ
- คุกกี้เซสชันเป็น httpOnly, SameSite=Lax และในโหมดจริงตั้ง Secure
- ฐานข้อมูลเก็บเฉพาะแฮชของโทเคน การออกจากระบบเพิกถอนแถวเซสชัน
- คำขอเปลี่ยนข้อมูลที่ส่ง Origin มาไม่ตรงกับโฮสต์ถูกปฏิเสธ
- รหัสลับเซสชันต้องยาวอย่างน้อย 32 ตัว และโหมดจริงปฏิเสธค่ารหัสตัวอย่าง

## สิทธิ์

- ทุกคำถามของการรับส่งกรองตามบทบาทก่อนส่งออกจากเซิร์ฟเวอร์ ไม่พึ่งการซ่อนปุ่มอย่างเดียว
- ผู้ปกครองที่ขอเด็กคนอื่นได้ผลว่าไม่พบข้อมูล
- คนขับที่เปิดรอบของรถคนอื่นได้ผลว่าไม่พบข้อมูล
- คำตอบ API ไม่เลือกคอลัมน์รหัสผ่าน

## ประวัติ

เหตุการณ์ที่เปลี่ยนสถานะเด็ก คำขอหยุด การแก้ย้อนหลัง การชำระเงิน และการแก้ข้อมูลหลัก เขียน audit พร้อมผู้ทำ เวลา สถานะเดิม และสถานะใหม่

คนขับและผู้ปกครองเปิดประวัติแก้ข้อมูลทั้งระบบไม่ได้

## ความปลอดภัยของเด็ก

- ปุ่มบันทึกบนหน้ารถใช้ได้หลังยืนยันว่าจอดแล้ว
- การเปิดทางนำร่องล็อกปุ่มบันทึกอีกครั้ง
- ปุ่มเด็กไม่อยู่และแจ้งหยุดต้องยืนยันซ้ำ
- ปิดรอบไม่ได้ถ้ายังมีเด็กไม่มีสถานะจบ
- ไม่มีฟิลด์พิกัดในเหตุการณ์ขึ้นลงรถ แม้ไคลเอนต์จะส่งมาก็ไม่ถูกบันทึก
- ชุดข้อมูลพัฒนาสร้างไม่ได้เมื่อสภาพแวดล้อมเป็น production

## สิ่งที่ยังต้องทำก่อนใช้กับเด็กจริง

- ตั้งรหัสฐานข้อมูลและ `SESSION_SECRET` ใหม่
- ใช้ HTTPS
- ทำข้อตกลงกับผู้ปกครองเรื่องข้อมูลที่เก็บ
- ตัดสินใจเรื่องผู้ให้บริการพุชแยกต่างหาก แล้วนำคีย์มาใส่ ห้ามถือว่ารายการในแอปเท่ากับพุชถึงเครื่อง
- ทบทวนการจำกัดการเดารหัสผ่านถ้ามีแอปมากกว่าหนึ่งโปรเซส
