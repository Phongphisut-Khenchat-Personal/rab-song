# พจนานุกรมข้อมูล

แหล่งที่บังคับใช้จริงคือ `prisma/schema.prisma` และการไมเกรต เอกสารนี้อธิบายความสัมพันธ์เพื่อให้อ่านคู่กับสคีมา

## ตาราง

- `User` บัญชีเข้าสู่ระบบ บทบาท OWNER, DRIVER หรือ GUARDIAN เบอร์โทรไม่ซ้ำ
- `Session` โทเคนที่เพิกถอนได้
- `Driver` โปรไฟล์คนขับ ผูกกับผู้ใช้หนึ่งคน เจ้าของที่ขับเองมีแถวนี้ด้วย
- `Guardian` โปรไฟล์ผู้ปกครอง
- `StudentGuardian` สิทธิ์ดูเด็ก ความสัมพันธ์ และผู้ปกครองหลัก คีย์คู่ไม่ซ้ำ
- `School` โรงเรียน จุดส่งตอนเช้าและจุดรับตอนเย็น
- `Vehicle` รถหนึ่งคันมีคนขับประจำ ความจุอย่างน้อย 1 และทะเบียนไม่ซ้ำ
- `Route` เส้นทางของหนึ่งโรงเรียนและหนึ่งคันรถ เช้าและเย็นเป็นคนละเส้นทางเพราะลำดับจุดต่างกัน
- `RouteStop` จุดบนเส้นทาง ลำดับไม่ซ้ำในเส้นทางเดียวกัน
- `StudentRouteAssignment` เด็กหนึ่งคนอยู่บนเส้นทางหนึ่งเส้นได้จุดรับและจุดส่งอย่างละหนึ่งจุด จุดทั้งสองต้องอยู่บนเส้นทางนั้น
- `Schedule` ตารางรายวันในสัปดาห์ของเส้นทางและรอบเช้าหรือเย็น เวลาวางแผนเป็นข้อความ HH:mm
- `ScheduleRun` รอบจริงของหนึ่งวัน ไม่ซ้ำต่อตารางและวันที่
- `StudentRunState` สถานะปัจจุบันของเด็กในรอบนั้น มีได้แถวเดียวต่อเด็กต่อรอบ
- `AttendanceEvent` ประวัติการกดบันทึก มี idempotency key ไม่ซ้ำ สถานะหลัก BOARD, ALIGHT, NO_SHOW, EXCUSE เกิดได้ครั้งเดียวต่อเด็กต่อรอบ ส่วน DELAY, ALTERNATE_RECEIVER และ CORRECTION ซ้ำได้
- `AbsenceRequest` คำขอลางดใช้รถ วันที่จบต้องไม่ก่อนวันที่เริ่ม และมี idempotency key
- `Notification` การแจ้งในแอปและการบันทึกว่าพุชยังตั้งค่าหรือไม่
- `Invoice` ค่าโดยสารรายเดือนต่อเด็ก ไม่ซ้ำต่อเดือน จำนวนเป็นสตางค์
- `Payment` เงินที่รับจริง ผูกกับใบแจ้งยอด และมี idempotency key
- `AuditLog` ผู้ทำ เวลา ชนิดรายการ รหัสรายการ ค่าเดิมและค่าใหม่
- `RunCheckpoint` ผลการตรวจลงครบที่โรงเรียน ออกจากโรงเรียน หรือปิดรอบ
- `SyncInbox` ผลของการซิงก์ที่เคยตอบไปแล้ว เพื่อให้ส่งคีย์เดิมซ้ำได้ผลเดิม

`LoginAttempt` ไม่ถูกเพิ่ม เพื่อคงสคีมาตามโดเมนที่กำหนด การจำกัดการเดารหัสจึงอยู่ที่โปรเซสเดียวตาม docs/ASSUMPTIONS.md

## สถานะเด็กในรอบ

`WAITING` ยังไม่ยืนยัน, `BOARDED` ขึ้นรถแล้ว, `ALIGHTED` ลงถึงจุดหมายของรอบนั้นแล้ว, `NO_SHOW` ไม่อยู่, `EXCUSED` แจ้งหยุด

การเปลี่ยนสถานะหลักตรวจในธุรกรรมและซ้ำไม่ได้เพราะดัชนีบางส่วนในไมเกรต
