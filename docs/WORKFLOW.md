# เวิร์กโฟลว์รับส่ง

ชื่อผลิตภัณฑ์ยังเป็น "รับส่ง" ตามรีโพซิทอรีเดิม ไม่ได้เปลี่ยนเป็นชื่ออื่น

## ของเดิมที่ยังใช้

การเข้าสู่ระบบ รอบเช้าเย็น รายชื่อตามจุด การบันทึกรับขึ้นและลง การแจ้งหยุด การแจ้งในแอป คิวออฟไลน์ ค่าโดยสารแบบบันทึกเอง และประวัติการแก้ไขยังทำงานอยู่ สถานะเดิม `WAITING`, `BOARDED`, `ALIGHTED`, `NO_SHOW`, `EXCUSED` ยังอยู่ในฐาน ระบบเพิ่ม `disposition` คู่กันเพื่อแยกเหตุการณ์ให้ชัดขึ้น

| ความต้องการ | ของเดิม | ช่องว่าง | สิ่งที่เปลี่ยน |
| --- | --- | --- | --- |
| ลูกค้าใหม่ก่อนเป็นนักเรียน | ไม่มี มีแต่นักเรียนที่เข้าตารางได้ทันที | ผู้สนใจถูกปนกับเด็กที่รับส่งได้ | ตาราง `ServiceLead` สถานะแยก และยังไม่สร้างนักเรียนจนกว่าจะลงทะเบียน |
| ตรวจจุดรับ | มีพิกัดบนจุด แต่ไม่มีคนยืนยัน | พิกัดถูกใช้ราวกับพร้อมให้บริการ | ตาราง `Place` สถานะต้องมีคนยืนยัน ระบบไม่ตัดสินความปลอดภัยของถนน |
| เวอร์ชันเส้นทาง | แก้ลำดับจุดทันที | รอบที่กำลังวิ่งเปลี่ยนตาม | สแนปช็อตของรอบที่ออกแล้วไม่ถูกแก้ รอบที่ยังเป็นแผนปรับได้ และมีการบันทึกผลกระทบ |
| ปิดรอบ | ตรวจสถานะเด็ก | ยังไม่บังคับตรวจรถว่าง | ต้องมีตรวจความพร้อมและตรวจรถว่างก่อนปิดรอบ |
| ผู้รับเด็ก | ใส่ชื่ออิสระ | ไม่รู้ว่าได้รับอนุญาต | รอบเย็นรับเฉพาะชื่อในรายชื่อผู้รับ |
| เวลาเดินทาง | ไม่มี | เสี่ยงต่อการใส่เวลาสมมติ | adapter OSRM/VROOM ถ้าไม่ได้ตั้งค่าจะแจ้งว่าคำนวณไม่ได้ |
| ออฟไลน์ | คิวสำเร็จหรือไม่สำเร็จ | ไม่มีสถานะกำลังส่ง | สถานะ `PENDING`, `SYNCING`, `SYNCED`, `FAILED` |

## ลูกค้าใหม่

`LEAD -> SURVEY_SCHEDULED -> LOCATION_PENDING_VERIFICATION -> ROUTE_ASSESSMENT -> QUOTE_PENDING -> AGREEMENT_PENDING -> REGISTRATION_PENDING -> SCHEDULE_PENDING -> READY_FOR_SERVICE -> ACTIVE`

ไป `REJECTED` ได้ก่อนยืนยันข้อตกลง ไป `CANCELLED` ได้จากเกือบทุกขั้น ไป `SUSPENDED` ได้เมื่อเริ่มบริการแล้ว การถอยกลับต้องมีเหตุผลและถูกบันทึกใน `AuditLog`

ประเมินเส้นทางได้เมื่อจุดเป็น `PARENT_CONFIRMED` หรือ `FIELD_VERIFIED` เท่านั้น นักเรียนในขั้นลงทะเบียนเป็น `DRAFT` และไม่เข้าตารางจนกว่าสถานะบริการจะเป็น `ACTIVE`

## เด็กในรอบรถ

เหตุการณ์ที่แยกกันคือ `NOT_PRESENT`, `ABSENCE_CONFIRMED`, `NOT_BOARDED`, `BOARDED`, `DROPPED_OFF`, `HANDED_TO_AUTHORIZED_PERSON` และ `UNKNOWN`

ปิดรอบไม่ได้ถ้ายังมี `UNKNOWN` หรือ `BOARDED` และไม่ได้ถ้ายังไม่มีผลตรวจความพร้อมกับผลตรวจรถว่างที่ผ่าน ระบบไม่ปล่อยเด็กให้อยู่ตามลำพังเมื่อไม่มีผู้รับที่ได้รับอนุญาต

คำขอหยุดหลังรอบเริ่มแล้วไม่เปลี่ยนสถานะเด็กเอง รอบที่ยังเป็นแผนและเด็กยังรออยู่ยังอัปเดตได้ เวลาตัดยอดที่แสดงคือ 21:00 ตามเวลาเอเชีย/กรุงเทพของวันก่อนใช้บริการ

## สมมติฐาน

- นักเรียนเดิมถูกคงสถานะ `ACTIVE` เพื่อไม่ให้รอบที่ใช้อยู่หาย
- นักเรียนที่เพิ่มจากฟอร์มเจ้าของหรือจากการลงทะเบียนลูกค้าใหม่เริ่มที่ `DRAFT`
- ธุรกิจนี้มีรถคันเดียวเป็นค่าเริ่มต้น แต่สร้างบัญชีคนขับเพิ่มได้
- เวลาจาก OSRM เป็นค่าประมาณ ไม่รับประกันการเดินทาง
- iOS ยังซิงก์เมื่อเปิดแอปขณะมีเน็ต ไม่ได้ซิงก์เบื้องหลังอย่างเสถียร
