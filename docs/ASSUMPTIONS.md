# ข้อสมมติที่ใช้เพราะยังไม่ได้ระบุเพิ่ม

1. ชื่อโปรเจกต์และรีโพซิทอรีคือ `rab-song` ชื่อบนหน้าจอคือ "รับส่ง"
2. รีโพซิทอรีบน GitHub เป็นแบบส่วนตัว เพราะระบบนี้เก็บข้อมูลส่วนบุคคลของเด็ก
3. เจ้าของขับเองคนเดียว จึงให้บัญชีเจ้าของมีโปรไฟล์คนขับและใช้งานหน้ารถได้ บัญชีคนขับคนอื่นใช้ได้เฉพาะรถที่ถูกมอบหมาย
4. ช่องทางเข้าใช้รอบนี้คือเว็บ mobile-first / PWA ไม่ได้ส่งแอปขึ้น App Store หรือ Play Store
5. ฐานข้อมูลพัฒนารันด้วย Docker Compose ที่พอร์ต 5432 และฐานทดสอบที่พอร์ต 5433
6. ร้านจริงมักวิ่งวันจันทร์ถึงศุกร์ แต่ข้อมูลพัฒนาสร้างตารางครบ 7 วัน เพื่อให้เปิดทดลองได้ในวันเสาร์และอาทิตย์ เจ้าของปิดวันที่ไม่วิ่งได้เอง
7. ค่าโดยสารบันทึกเป็นสตางค์จำนวนเต็ม ยังไม่มี PromptPay หรือเกตเวย์
8. การแจ้งผู้ปกครองที่ทำงานจริงในรอบนี้คือรายการในแอป พุชเบราว์เซอร์และ SMS ยังไม่ถูกตั้งค่า และระบบจะไม่รายงานว่าส่งสำเร็จ
9. iOS ไม่รองรับการซิงก์เบื้องหลังอย่างเสถียร คิวจะถูกส่งเมื่อเปิดแอปขณะมีเน็ต
10. การยืนยัน "จอดรถแล้ว" เป็นมาตรการในหน้าจอ ไม่ใช่การตรวจจับการขับจากเซ็นเซอร์
11. พิกัดในข้อมูลพัฒนาเป็นจุดสมมติสำหรับทดลองเปิดแผนที่ ไม่ใช่บ้านของนักเรียนจริง
12. เซสชันอยู่ได้ 16 ชั่วโมงต่อการเข้าสู่ระบบหนึ่งครั้ง เพื่อให้เข้าตอนเช้าและยังใช้รอบเย็นได้
13. การจำกัดจำนวนครั้งที่รหัสผ่านผิดใช้หน่วยความจำของโปรเซสเดียว ถ้ารันหลายอินสแตนซ์ต้องย้ายไปเก็บในฐานข้อมูลหรือ Redis ภายหลัง
14. ไม่เก็บรูปเด็ก เลขบัตรประชาชน หรือใบขับขี่ เพราะยังไม่จำเป็นต่อการรับส่ง
15. ภาษาอังกฤษในโค้ดและชื่อฟิลด์ใช้เพื่อการดูแลระบบ ข้อความที่ผู้ใช้เห็นเป็นภาษาไทย
