# รับส่ง (Rab-Song)

ระบบรับส่งนักเรียนสำหรับธุรกิจรถรับส่งรายย่อยที่เจ้าของขับเอง ใช้งานผ่านมือถือ Android และ iOS ในเบราว์เซอร์ หรือเพิ่มไปที่หน้าจอหลักได้

รีโพซิทอรีนี้เป็นส่วนตัวเพราะระบบเก็บข้อมูลส่วนบุคคลของเด็ก ข้อมูลในคำสั่ง seed เป็นบุคคลสมมติสำหรับพัฒนาเท่านั้น

## สิ่งที่ระบบทำได้ตอนนี้

- เข้าสู่ระบบและแยกสิทธิ์เจ้าของ คนขับ และผู้ปกครอง
- ตารางรอบเช้าและรอบเย็น รายชื่อเรียงตามจุด
- บันทึกรับขึ้นรถ ส่งถึงจุดหมาย เด็กไม่อยู่ ผู้ปกครองแจ้งหยุด รถล่าช้า และผู้รับแทน
- ตรวจว่าเด็กลงครบก่อนปิดรอบ
- ผู้ปกครองเห็นเฉพาะเด็กของตน แจ้งหยุด และดูประวัติ
- แจ้งในแอปเมื่อเซิร์ฟเวอร์บันทึกแล้ว พร้อมบอกตรง ๆ ว่าพุชยังไม่ได้ตั้งค่า
- คิวออฟไลน์สำหรับรายการรับส่งและคำขอหยุด โดยยังไม่ขึ้นว่าสำเร็จจนกว่าเซิร์ฟเวอร์ยืนยัน
- จัดการนักเรียน โรงเรียน จุดรับส่ง รถ ค่าโดยสารแบบบันทึกเอง และประวัติการแก้ไข
- เปิดทางนำร่องภายนอก โดยไม่ใช้พิกัดเป็นหลักฐานว่าเด็กขึ้นหรือลงรถ

## สิ่งที่ยังไม่ทำ

- ไม่มีแอปใน App Store หรือ Play Store
- ไม่ส่งพุชหรือ SMS จนกว่าจะมีคีย์ผู้ให้บริการ
- ไม่มีเกตเวย์รับเงินหรือ PromptPay
- ไม่ได้ดีพลอยขึ้นเซิร์ฟเวอร์จริงในรอบนี้
- ภาพ Docker ของแอปมีไฟล์ให้สร้าง แต่ยังไม่ได้빌ด์และรันบนโฮสต์จริง
- การจำกัดการเดารหัสผ่านอยู่ที่โปรเซสเดียว
- การยืนยันว่าจอดรถแล้วเป็นมาตรการในหน้าจอ ไม่ได้ตรวจจากเซ็นเซอร์รถ

## ติดตั้งเพื่อพัฒนา

ต้องมี Node.js 22 ขึ้นไป, npm และ Docker Desktop

```powershell
cd $HOME\Projects\rab-song
copy .env.example .env
```

แก้ `SESSION_SECRET` ใน `.env` ให้เป็นข้อความสุ่มยาวอย่างน้อย 32 ตัว แล้วเปิดฐานข้อมูล

```powershell
docker compose up -d
npm install
npx prisma migrate deploy
npm run db:seed
npm run dev
```

เปิด http://localhost:3000

พอร์ตฐานพัฒนาคือ **5436** และฐานทดสอบคือ **5437** เพื่อไม่ไปชน Postgres อื่นบนเครื่อง

### บัญชีตัวอย่าง

ใช้ได้หลัง `npm run db:seed` และเฉพาะเมื่อ `APP_ENV=development` กับ `SEED_DATASET=development`

| บทบาท | เบอร์ | รหัส |
| --- | --- | --- |
| เจ้าของที่ขับเอง | 0800000001 | DevOwner#2569 |
| ผู้ปกครอง ก | 0800000002 | DevGuard#2569 |
| ผู้ปกครอง ข | 0800000003 | DevGuard#2569 |

คำสั่ง seed ลบข้อมูลในฐานที่ชี้ไว้ จึงปฏิเสธถ้าไม่ใช่สภาพแวดล้อมพัฒนา หรือถ้าระบุฐานที่ไม่ใช่ localhost

## ทดสอบและบิลด์

```powershell
npm test
npm run build
```

เทสครอบคลุมการเข้าสู่ระบบ สิทธิ์ การยืนยันรับส่ง การแจ้งหยุด การกดซ้ำ และการซิงก์ ตัวรันเทสบังคับใช้ฐาน `rabsong_test` ที่พอร์ต 5437 แม้เครื่องจะตั้ง `DATABASE_URL` ไว้เป็นฐานพัฒนา จึงไม่ลบข้อมูลตัวอย่างบนพอร์ต 5436

## ขึ้นระบบจริง

1. ตั้ง PostgreSQL ที่ไม่ใช่รหัสในไฟล์ตัวอย่าง
2. ตั้งค่าเหล่านี้บนโฮสต์

```text
APP_ENV=production
DATABASE_URL=postgresql://...
SESSION_SECRET=ข้อความสุ่มยาวอย่างน้อย 32 ตัว
OWNER_NAME=ชื่อเจ้าของ
OWNER_PHONE=08xxxxxxxx
OWNER_PASSWORD=รหัสยาวอย่างน้อย 10 ตัว และห้ามใช้รหัสตัวอย่าง
```

3. รัน

```powershell
npx prisma migrate deploy
npm run owner:create
npm run build
npm start
```

ห้ามรัน `npm run db:seed` บนระบบจริง คำสั่งจะปฏิเสธถ้า `APP_ENV` ไม่ใช่ `development`

ถ้าจะทำอิมเมจ ให้ใช้ `Dockerfile` แล้วส่ง environment ตอนรันคอนเทนเนอร์ ยังไม่ได้พิสูจน์การรันอิมเมจนี้บนเซิร์ฟเวอร์

การแจ้งเตือนพุชจะขึ้นว่ายังไม่ได้ตั้งค่าจนกว่าจะมีบริการภายนอกและนำตัวส่งจริงมาต่อใน `src/server/notifications.ts` อย่าเปลี่ยนข้อความว่าส่งสำเร็จก่อนผู้ให้บริการตอบรับ
